# 解析プロセスの登録

解析の種類ごとに `<process-id>/` を作成します。process-idは英数字とハイフンなどからなる固定識別子とし、入力ファイル名や実行日を識別子に含めません。実行ごとの差異はworkspaceのrun-idで分離します。

開発者は `_template/` をコピーして名前を変更し、GH定義を `gh/`、配布可能な固定資材を `assets/` に置き、READMEを記入します。通常の利用者や解析中のAgentはプロセスを追加・変更しません。

`_template/` は実行対象に含めません。`process-test/` は共有テストGHの実行確認済み接続設定です。`process.json` に公開入力名等を記録します。GH本体はまだ配布物に含めず、利用者のconfigからパスを指定します。初版のrunnerは公開入力がファイルパス1つのGHに対応します。
